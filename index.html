What's inside

part1/security-led

Exploratory testing & bug report

Four bugs ordered by priority: a prompt-injection system-prompt leak, no content moderation, a free-tier bypass, and an input-validation gap - each with evidence, plus a passive security review.

part2/11 / 11 green

Playwright E2E suite

Page Object Model, explicit waits, meaningful assertions. Passing against live Trupeer, with a custom reporter that shows what changed since the last run.

part3/AI validation

LLM-as-judge harness

Grades each "Modify Script with AI" rewrite against a rubric with confidence scores, and catches a nuance a string match cannot - the feature over-rewriting instead of staying on task.

qa-system/bonus

Regression-aware QA system

Remembers every run and classifies each check - stable / regression / fixed / suspicious-pass / new-bug - then explains a regression from its evidence diff and a model-written likely cause.

02

Findings worth your first five minutes

security

Prompt injection leaks the system prompt

A two-step injection makes "Modify Script with AI" output its entire system prompt, defeating its own confidentiality and injection-defense rules - and the leaked prompt even explains a Part 3 result (it instructs the model to over-rewrite).

AI

An LLM judge that catches what assertions miss

Asked only to add a call to action, the feature rewrote the whole script; the judge failed it on "stayed on task" with a cited reason. Re-run it and the numbers change - every verdict is a live call, nothing hardcoded.

business

The free tier is bypassable

Email verification is satisfied by disposable inboxes, so the 3-video limit - the boundary the free/paid model depends on - can be reset indefinitely at zero cost.

judgment

Tested responsibly

Prompt-injection, header, and secret-exposure checks were non-destructive and run on my own account. SQL/command injection was deliberately not attempted against the production app - that belongs in a controlled staging environment.
